1. H/W 구성(/model_ori 폴더)
  * LimX Dynamics Tron1(2족 점 포인트 보행 로봇)
    - 상체 전면 충격 완충 범퍼 장착 (스테이션 테이블 모서리 거치 도킹용)
    - 상체 3구 컵홀더 트레이 장착 (물병 적재 및 운반용)
  * Universal Robots UR5e(6축 협동 로봇팔)
  * Robotiq 2F-85(2지 평행 그리퍼)
  * Realsense D435i(RGB-D 카메라) => Robotiq 2F-85 그리퍼 베이스 중앙부 장착 (Eye-in-Hand 방식)
  * Station Table (스테이션 작업대)
    - Tron1 상체 전면 범퍼 안착용 완충 모서리(도킹 레지) 구비
    - 물병 Place 지정 구역 마킹

2. 역할
  * Tron1
    : 시작 위치에서 상체 트레이에 적재된 물병을 싣고 UR5e 앞 인계 구역까지 보행 이동. 인계 구역 도달 시 상체 전면 범퍼를 테이블 모서리에 가볍게 기대어(Table Bumper Rest) 3점 지지를 형성하고, 발구름을 완전히 멈추어(Stance Lock) 트레이를 무진동 정지 상태로 유지. 작업 완료 후 뒤로 물러나 시작 위치로 복귀.
  * Realsense D435i (Eye-in-Hand)
    : Robotiq 2F-85 그리퍼 가운데에 설치되어 로봇팔 관측 대기 자세(Scan Pose)에서 Tron1의 도착 및 도킹 정지를 감지. 트레이 위 물병의 RGB-D 데이터를 획득하여 3D 기하학적 중심점을 추출하고 UR5e 제어기에 파지 목표 좌표 송신.
  * Universal Robots UR5e + Robotiq 2F-85
    : 그리퍼 중앙의 D435i로부터 수신한 기하학적 중심점 좌표를 기반으로 Tron1 트레이 위의 물병을 Pick하여 스테이션 테이블의 지정 구역에 직립 Place. 물병을 놓은 후 다시 트레이 관측 포즈로 복귀하여 다음 물병 스캔 유도.
    
3. 정상 작동 시나리오
  3.1. (Tron1) 시작 위치에서 물병이 적재된 트레이를 싣고 인계 구역까지 RL 보행으로 이동.
  3.2. (Tron1) 인계 구역 도달 시, 상체 전면 범퍼를 스테이션 테이블 모서리에 살짝 기대어 안착(Table Bumper Rest). 바닥의 두 발과 테이블 접촉점의 3점 지지가 형성되면 RL 발구름을 완전히 멈추고(Stance Lock) 트레이를 수평 무진동 정지 상태로 고정.
  3.3. (UR5e + D435i) 초기 대기/관측 자세(Home/Scan Pose: 그리퍼 카메라가 인계 구역을 하향 조준)에서 D435i가 Tron1의 도착 및 범퍼 접촉을 감지.
  3.4. (Realsense D435i) Tron1이 3초 동안 흔들림 없이 정지 상태(READY_FOR_PICK)를 유지함을 확인 후 트레이 위 물병 영역 스캔.
  3.5. (Realsense D435i) 그리퍼 카메라 좌표계 기준으로 가장 파지하기 적합한 1번째 물병의 3D 기하학적 중심점을 추출하여 UR5e 제어기에 송신.
  3.6. (반복 루프 시작: 물병 1개씩 순차 Pick & Place)
    3.6.1. (Universal Robots UR5e + Robotiq 2F-85) 목표 물병 상공 사전 접근(Approach) 후 하강하여 물병 몸통을 파지(Grasp)하고 수직 상승(Lift).
    3.6.2. (Universal Robots UR5e + Robotiq 2F-85) 파지한 물병을 스테이션 테이블의 지정 구역으로 이송 후 테이블 바닥면에 안전하게 직립 안착(Place) 및 그리퍼 개방(Release).
    3.6.3. (UR5e + D435i) 그리퍼를 개방한 UR5e가 다시 트레이 상공의 관측 대기 자세(Scan Pose)로 복귀(Retreat).
    3.6.4. (Realsense D435i) 관측 포즈에 도달한 D435i가 트레이를 즉시 재스캔하여 남은 물병 유무 확인:
      - 남은 물병이 1개 이상인 경우: 다음 물병의 3D 중심점을 계산하여 UR5e에 송신 후 3.6.1 단계로 반복 진행.
      - 남은 물병이 0개인 경우: '트레이 비움(Tray Cleared)' 판정 후 3.7 단계로 분기.
  3.7. (UR5e & D435i) 모든 물병의 이송 완료 메시지('ALL_BOTTLES_TRANSFERRED')를 Tron1 및 상위 관제 시스템에 송신.
  3.8. (Tron1) 완료 메시지 수신 즉시 RL 발구름을 재개하여 테이블 모서리에서 뒤로 한 걸음 안전하게 물러난 후(언도킹), 시작 위치로 복귀 보행.
 
4. 예외 상황 시나리오
  - 상황 1) [3.2단계 관련] Tron1 도킹 접근 시 테이블 모서리 접촉 미흡 (도킹 오차/거리 부족)
    : 대응 => D435i가 트레이 정지 위치가 정상 도킹 영역에 미달함을 감지하면, Tron1에 미세 전진(Nudge Forward, 예: +2cm) 명령을 내려 범퍼가 테이블에 확실히 밀착되도록 보정.

  - 상황 2) [3.4단계 관련] Tron1 도착 직후 물병이 0개로 인식된 경우 (운반 중 낙하 또는 미적재)
    : 대응 => 루프(3.6)를 시작하지 않고 즉시 'Empty Tray' 경고를 관제 시스템 및 Tron1에 송신하여 복귀 또는 작업 중단 처리.

  - 상황 3) [3.5 및 3.6.4단계 관련] 물병이 트레이 내에서 심하게 쓰러져 있거나 겹쳐서 중심점 추정 불가
    : 대응 => 불안정한 물병은 스킵(Skip)하고 정상 직립된 다른 물병의 중심점을 우선 추출. 정상 물병이 하나도 없으면 비상 정지 및 관리자 알림.

  - 상황 4) [3.6.1단계 관련] UR5e 파지 실패(헛파지) 또는 리프트 도중 미끄러짐(Slip) 감지
    : 대응 => 그리퍼 파지 폭 센서 및 부하 전류로 실패 감지 시, 즉시 상방으로 후퇴한 뒤 3.6.3(Scan Pose)으로 복귀하여 D435i로 재스캔 후 1회 재시도. 연속 2회 실패 시 작업 일시 중지.

  - 상황 5) [3.6.2 ~ 3.6.3단계 관련] Eye-in-Hand 카메라 특성에 따른 이동 중 시야 왜곡 및 차폐
    : 대응 => 물병 파지 및 Place 이동 중에는 카메라 비전 인식을 일시 비활성화(Vision Idle)하고, 오직 관측 포즈(Scan Pose)에 정지 도달했을 때만 안정적으로 스캔 트리거를 인가하여 오인식 원천 차단.

  - 상황 6) [3.6단계 전체 관련] UR5e 작업 중 외력 등에 의해 Tron1 접촉 자세 불안정(도킹 이탈/흔들림) 감지
    : 대응 => Tron1 IMU 가속도/자이로 급변 또는 D435i 상의 트레이 위치 급변 감지 시, 즉시 E-Stop 신호를 브로드캐스트하여 로봇팔을 현 위치에서 즉시 일시 정지(Hold)하여 충돌 방지.

  - 상황 7) [3.7 ~ 3.8단계 관련] 작업 완료 신호 송수신 타임아웃
    : 대응 => UR5e 완료 신호 발행 후 일정 시간(10초) 내 Tron1 응답(ACK) 부재 시 재전송(Ping) 후 무응답 지속 시 시스템 안전 정지.
