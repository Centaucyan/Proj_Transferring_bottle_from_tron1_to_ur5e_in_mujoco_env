1. H/W 구성(/model_ori 폴더)
  * LimX Dynamics Tron1(2족 보행 로봇)
  * Universal Robots UR5e(로봇팔)
  * Robotiq 2F-85(그리퍼)
  * Realsense D435i(RGB-D 카메라)

2. 역할
  * Tron1
    : 누군가 병류를 Tron1위에 설치된 Tray에 놓으면 이를 UR5e 근처의 인계 구역까지 옮김
  * Realsense D435i
    : 스테이션 테이블에 설치되어 Tron1이 인계 구역으로 오는 것을 인식하고, Tron1이 정지하면 병류의 기하학적 중심점을 추출하고 이 값을 UR5e에 송신
  * Universal Robots UR5e + Robotiq 2F-85
    : Realsense D435i로부터 수신받은 기하학적 중심점을 이용하여 그리퍼를 이용해 Tron1 위의 병류를 Pick 후 스테이션 테이블의 지정 구역에 Place
    
3. 정상 작동 시나리오
  3.1. (Tron1) 시작 위치에서 병류가 놓인 트레이를 싣고 인계 구역까지 이동
  3.2. (Tron1) 인계 구역에서 트레이 위치를 스테이션 테이블 높이로 맞추고 정지
  3.3. (Realsense D435i) 스테이션 테이블의 카메라가 Tron1의 도착을 감지
  3.4. (Realsense D435i) Tron1이 3초 동안 정지 상태를 유지함을 확인 후 트레이 위의 병류 인식
  3.5. (Realsense D435i) UR5e와 가장 가까운 1번째 병류의 기하학적 중심점을 추출하여 UR5e에 송신
  3.6. (반복 루프 시작)
    3.6.1. (Universal Robots UR5e + Robotiq 2F-85) 수신한 좌표의 병을 Pick하여 스테이션 테이블의 지정 구역으로 이동(Place)
    3.6.2. [병렬 진행] (Realsense D435i) UR5e가 트레이 구역을 벗어나 Place하는 동안, D435i는 트레이를 실시간 스캔하여 남은 병 유무 확인
      - 남은 병이 1개 이상이면: 다음으로 가까운 병류의 기하학적 중심점을 미리 계산하고 송신 대기
      - 남은 병이 0개이면: '모든 병 집음(Tray Cleared)' 상태로 대기
    3.6.3. (Universal Robots UR5e + Robotiq 2F-85) Place 완료 후 '동작 완료' 신호를 D435i에 송신
    3.6.4. (Realsense D435i) '동작 완료' 신호 수신 즉시 분기:
      - 대기 중인 다음 병 좌표가 있으면: UR5e에 즉시 송신 후 3.6.1 단계 반복
      - 남은 병이 0개였으면: 3.7 단계로 이동
  3.7. (Realsense D435i & UR5e) 모든 병류 이송 완료 메시지를 Tron1 및 관제 시스템에 송신
  3.8. (Tron1) 완료 메시지 수신 후 트레이 높이를 원복하고 시작 위치로 복귀
 
4. 예외 상황 시나리오
  - 상황 1) [3.4단계 관련] Tron1 도착 직후 병이 0개로 인식된 경우 (운반 중 낙하 또는 미적재)
    : 대응 => 루프(3.6)를 시작하지 않고 즉시 'Empty Tray' 에러를 Tron1에 송신하여 복귀 또는 작업 중단 처리.

  - 상황 2) [3.5 및 3.6.2단계 관련] 사전 스캔 중 병이 쓰러져 있거나 겹쳐서 중심점 추정이 불가한 경우
    : 대응 => 불안정한 병은 건너뛰고(Skip), 정상 직립된 다른 병의 중심점을 계산하여 대기. 정상 병이 하나도 없으면 에러 알림.

  - 상황 3) [3.6.1단계 관련] UR5e 파지 실패(헛파지) 또는 들어올릴 때 미끄러짐(Slip) 발생
    : 대응 => 그리퍼 파지 센서로 실패 감지 시, 3.6.3(완료) 대신 '작업 실패'를 알리고 안전 위치로 후퇴 후 1회 재시도. 재실패 시 3.6.2의 사전 스캔 결과를 무효화하고 트레이 전체 재스캔.

  - 상황 4) [3.6.2단계 관련] UR5e 로봇팔에 의해 카메라 시야가 일시적으로 가려지는 경우 (Occlusion)
    : 대응 => UR5e 엔드이펙터가 트레이 안전 경계(Bounding Box)를 완전히 벗어났음을 확인(로봇 위치 토픽 구독)한 시점에 스캔 트리거.

  - 상황 5) [3.2 및 3.6.1단계 관련] Tron1 정지 위치 오차로 UR5e 작업 반경(Reach/IK) 초과
    : 대응 => MoveIt2 역기구학(IK) 솔루션 탐색 실패 시 파지를 시도하지 않고 Tron1에 미세 전진/후진 조정 명령 송신.

  - 상황 6) [3.6.1단계 관련] UR5e 작업 중 Tron1의 자세 불안정(외란/흔들림) 발생
    : 대응 => Tron1 IMU 이상 감지 시 즉시 E-Stop 신호를 브로드캐스트하여 로봇팔 동작을 일시 정지하고 충돌 방지.

  - 상황 7) [3.6.3 ~ 3.6.4단계 관련] 로봇 간 작업 완료 메시지 통신 타임아웃
    : 대응 => D435i가 일정 시간(예: 30초) 동안 완료 메시지를 받지 못할 경우, UR5e 상태 확인(Ping) 후 무응답 시 시스템 안전 정지.
